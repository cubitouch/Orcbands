# Orcbands Tree Asset Lab

[Interactive viewer](https://cubitouch.github.io/Orcbands/) — original low-poly evergreen, shown as an actual WebGL mesh. This is **not** the Unity game.

## Reusable mesh

The geometry is generated by `tools/generate-tree.mjs`. Run `node tools/generate-tree.mjs` to regenerate the files checked into `preview/assets/`:

- `low-poly-pine-01.obj`: 109 vertices, 144 polygon faces, approximately 4.58 units tall and 2.72 units wide.
- `low-poly-pine-01.mtl`: seven flat-color bark and needle materials.

Four foliage tiers are offset to avoid a perfect stack of identical cones. The tree is static: there is no rig, wind deformation, collider, LOD system, Unity prefab or resource-gathering behavior.

## Unity import

Place both files in the same Assets folder. Unity can import the OBJ; reconnect materials if the MTL is not handled correctly. Verify scale, normals and clipping in Unity before accepting it as production art.

## Viewer

`Single tree` offers close inspection. `Small grove` uses seven clones with varying scale and rotation, not seven unique meshes. `Wireframe`, `Auto rotate`, `Reset camera` and `?scene=grove` support review.

## CI and deployment

GitHub Actions checks that the OBJ and MTL regenerate bit-for-bit, checks JavaScript syntax and runs a headless Chromium/WebGL visual smoke test. Pushes to main publish the static preview via GitHub Pages.

The earlier bespoke orc modelling assets and workflows have been retired. Their history remains accessible through old commits/PRs.
