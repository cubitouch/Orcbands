# Orcbands Asset Lab

[Interactive viewer](https://cubitouch.github.io/Orcbands/) — original low-poly evergreen, shown as an actual WebGL mesh. This is **not** the Unity game.

## Reusable mesh

The geometry is generated by `tools/generate-tree.mjs`. Run `node tools/generate-tree.mjs` to regenerate the files checked into `preview/assets/`:

- `low-poly-pine-01.obj`: 109 vertices, 144 polygon faces, approximately 4.58 units tall and 2.72 units wide.
- `low-poly-pine-01.mtl`: seven flat-color bark and needle materials.

Four foliage tiers are offset to avoid a perfect stack of identical cones. The tree is static: there is no rig, wind deformation, collider, LOD system, Unity prefab or resource-gathering behavior.

## Unity import

Place both files in the same Assets folder. Unity can import the OBJ; reconnect materials if the MTL is not handled correctly. Verify scale, normals and clipping in Unity before accepting it as production art.

## Viewer

`Single tree` offers close inspection. `Forest grove` uses 244 uniformly scaled and rotated instances of the preserved pine, a terrain-integrated worn earth path, three grass forms and three rock silhouettes. It opens onto a broad forest floor with a central clearing. See [ENV-02](environment-env-02.md) for the original composition and [path naturalism](path-naturalism.md) for the current ground treatment and WebGL screenshots. `Wireframe`, `Auto rotate`, `Reset camera` and `?scene=grove` support review. The grove also offers RTS, path, ground-level and wide camera presets; portrait screens receive wider camera framing. Reset clears orbit damping and rotation for a repeatable starting view.

## Forest camp and campfire

The hut clearing now sits within 244 pines, with denser connecting woodland and a stone-ring campfire. [Forest camp](forest-camp.md) records the current composition, deterministic animated geometry, screenshots and performance.

## Timber Hut 01

`Timber hut` and `?scene=hut` open the new original building. Front/rear/roof/entrance presets, wireframe, auto rotation and reset support inspection; the hut is also placed in the grove clearing. [Timber Hut 01](timber-hut-01.md) documents the authored mesh, downloadable OBJ/MTL, actual browser captures and limitations. Pine 01's source assets and generator remain unchanged.

## CI and deployment

GitHub Actions checks that the OBJ and MTL regenerate bit-for-bit, checks JavaScript syntax and runs a headless Chromium/WebGL visual smoke test on desktop and portrait viewports. The test exercises pointer orbit, wheel zoom, pan, auto rotation, reset and actual CDP touch gestures. Layout validation checks path clearance, clearing space, finite buffers, upward-facing path triangles and bit-for-bit geometry reproduction. CI captures the unchanged Single Tree, hut studio and detail angles, grove views and mobile framing in the `orcbands-forest-webgl-smoke` artifact. Pushes to main publish the static preview via GitHub Pages.

The earlier bespoke orc modelling assets and workflows have been retired. Their history remains accessible through old commits/PRs.
